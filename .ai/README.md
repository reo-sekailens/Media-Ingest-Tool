# AI collaboration assets

This folder contains portable prompts for AI coding assistants. They complement, rather than replace, repository instructions and the memory bank.

Use the prompts by supplying the relevant request, current repository state, and any applicable memory-bank entries. Never paste secrets or unredacted production data into an assistant session.

## Available prompts

- [`implement.md`](prompts/implement.md): scoped implementation work
- [`review.md`](prompts/review.md): evidence-based change review
- [`handoff.md`](prompts/handoff.md): concise continuation context
