# Memory Bank

This folder is the durable working context for people and AI agents contributing to this repository. It records only verified project information, active work, decisions, and evidence.

## Maintenance rule

Before starting non-trivial work, read the files relevant to the change. After completing work, update the active context, progress, task index, decisions, and certification matrix when they are affected. Record facts only when they are evidenced in the repository, approved requirements, or verification output; label unknowns and blockers instead of guessing. Keep entries concise, dated, and linked to the relevant file, issue, or command when available.

## Conventions

- Use Markdown and stable, descriptive filenames.
- Add decisions chronologically; do not rewrite prior rationale without noting why.
- Move completed work from active context to progress.
- Keep secrets, credentials, personal data, and unverified production claims out of this folder.
